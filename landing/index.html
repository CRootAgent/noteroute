Ambil File dari Laptop

Menelusuri direktori laptop dari HP dan mengunduh berkas fisik (PDF, DOCX, TXT, MD) langsung ke folder Downloads ponsel secara asinkron.

Document Chat & Sitasi

Tanya-jawab isi berkas ala NotebookLM dengan Citation Badges transparan yang menunjukkan nomor halaman dan cuplikan teks rujukan.

Multi-LLM Switcher

Bebas berganti otak AI: Gemini 1.5 Flash (Konteks 1M), Groq Llama 3.3 (Kilat 300 token/s), DeepSeek R1/V3, atau bridge 9Router lokal.

Smart Failover (HTTP 429)

Otomatis mendeteksi limit kuota API dan mengalihkan ke model cadangan secara transparan tanpa menginterupsi sesi obrolan pengguna.

Panduan Cepat Setup NoteRoute

Pilih topik panduan di bawah untuk melihat langkah konfigurasi interaktif:

Langkah 1: Setup Agen Sinkronisasi Dokumen di Laptop

Agen laptop bertugas membaca folder materi kuliah dan menyinkronkan berkas ke cloud backend NoteRoute agar bisa diakses dari HP Android Anda.

# 1. Masuk ke direktori proyek server NoteRoute
cd noteroute/server

# 2. Pasang dependensi dan jalankan server
npm install
npm start

Folder dokumen Anda otomatis terindeks dan dapat ditelusuri langsung melalui layar File Explorer di HP Android.
